1. ЧТО ДЕЛАЕТ FORGE

Вы описываете деталь: размеры, сталь, сколько штук в год. FORGE по этим данным:

  - считает поковку: припуски, допуски, размеры и массу по ГОСТ 7505-89 (штамповка)
    или ГОСТ 7829-70 (свободная ковка);
  - подбирает заготовку из сортамента ГОСТ 2590-2006 (круг), считает облой, угар и потери на резку;
  - назначает нагрев: температуру, интервал ковки, выдержку и термообработку для выбранной стали;
  - выбирает оборудование: молот, кривошипный пресс (КГШП), горизонтально-ковочную машину (ГКМ),
    гидравлический пресс, обрезной пресс;
  - строит технологический маршрут, то есть список операций по порядку, и переходы внутри операций;
  - заполняет маршрутную карту по ГОСТ 3.1118-82 и карту техпроцесса ковки и штамповки
    по ГОСТ 3.1403-85 с основной надписью по ГОСТ 3.1103-82;
  - печатает всё это или сохраняет в PDF и Excel.

Маршрут может строить локальная нейросеть (через программу Ollama) или набор правил, зашитый
в FORGE. Все числа: массы, размеры, температуры, усилия считает сама программа по справочникам.
Нейросеть отвечает только за решения и текст: какие операции нужны, в каком порядке и почему.
Каждое число в результате можно проследить до источника, это вкладка «Источники».

FORGE не чертит чертёж поковки и не заменяет технолога: готовые карты нужно проверить
и подписать. Значения, которых нет в ГОСТ, программа помечает «не ГОСТ».


2. ЧТО НУЖНО ДЛЯ РАБОТЫ

Обязательно:
  - Windows 10 или 11;
  - браузер Microsoft Edge или Google Chrome (Edge есть в любой Windows 10/11, ставить ничего
    не надо). В нём FORGE открывает своё окно.

Только для запуска из исходников:
  - Python 3.10 или новее, python.org. При установке поставьте галочку «Add python.exe to PATH».

Только если хотите, чтобы маршрут строила нейросеть:
  - программа Ollama (FORGE поставит её сам, см. раздел 14);
  - модель, 2,5–19 ГБ на диске в зависимости от модели;
  - память: для основной модели qwen2.5:7b нужно 16 ГБ оперативной памяти или видеокарта
    от 6 ГБ. На слабом компьютере (8 ГБ, без видеокарты) берите модель из группы «Слабый компьютер».

Интернет нужен только для трёх вещей: скачать FORGE, скачать модель и проверить обновления.
Расчёт, маршрут и нейросеть работают без интернета, данные детали никуда не отправляются.


3. УСТАНОВКА И ЗАПУСК

3.1. Готовая программа FORGE.exe (так проще всего)

  1. Откройте https://github.com/WiWaSu/forge/releases/latest
  2. В блоке Assets нажмите FORGE.exe, файл скачается (около 10 МБ).
  3. Создайте отдельную папку, например «Документы\FORGE», и перенесите FORGE.exe туда.
     Рядом с FORGE.exe программа создаёт свои файлы (настройки, история, выгрузки),
     и в папке «Загрузки» они перемешаются с чужими.
  4. Дважды щёлкните FORGE.exe.
  5. Windows может показать синее окно «Windows защитила ваш компьютер». Так бывает со всеми
     программами без платной цифровой подписи. Нажмите «Подробнее», потом «Выполнить в любом случае».
     Антивирус тоже может насторожиться: FORGE.exe собран PyInstaller, а такие файлы антивирусы
     иногда проверяют дольше обычного.
  6. Через 2–5 секунд откроется окно FORGE. При самом первом запуске сначала будет экран
     настроек (раздел 4).

Чтобы выйти, закройте окно FORGE крестиком. Программа выключится сама.

3.2. Из исходников

  1. Поставьте Python 3.10+ (см. раздел 2).
  2. Скачайте код: на странице https://github.com/WiWaSu/forge кнопка Code, затем Download ZIP.
     Распакуйте архив.
  3. Дважды щёлкните serve.bat в распакованной папке.
  4. Появится чёрное окно консоли и окно FORGE. Консоль не закрывайте, пока работаете:
     в ней работает программа.

Другие файлы в папке с кодом:
  test.bat   прогнать проверки программы (190 тестов, идут меньше минуты);
  build.bat  собрать свой FORGE.exe (нужен PyInstaller: pip install pyinstaller);
  forge.bat  меню для разработчика: расчёт и проверка модели из консоли.

3.3. Если окно не открылось

Если на компьютере нет ни Edge, ни Chrome, FORGE откроется обычной вкладкой в браузере
по умолчанию. Тогда выйти можно только так: закрыть вкладку и нажать Ctrl+C в чёрном окне
консоли (или закрыть консоль).

Если не открылось вообще ничего, загляните в файл forge.log рядом с FORGE.exe:
там написано, на каком адресе запустилась программа (например http://127.0.0.1:8765),
этот адрес можно открыть в любом браузере вручную.


4. ПЕРВЫЙ ЗАПУСК: ЭКРАН НАСТРОЕК

[screens/07-settings.png]

При первом запуске FORGE спрашивает, как вам удобнее работать. Всё это потом можно поменять
кнопкой «Настройки» в правом верхнем углу.

Левая половина, «Как вам удобнее работать?»:
  - вид экрана A, B или C (подробно в разделе 15). Если не знаете, что выбрать, оставьте
    «A. Рабочее место»: в нём всё видно сразу;
  - тема: «Как в системе», «Светлая» или «Тёмная»;
  - цвет: цвет кнопок и выделения. Щёлкните по цветному квадрату и выберите любой цвет.
    Кнопка «Как в пульте» возвращает исходный тёмно-серый.

Правая половина, «Какой моделью строить маршрут?»:
  - список скачанных моделей. Пока Ollama не запущена, список пустой и выбран вариант
    «Без нейросети». Так можно работать: маршрут будут строить правила.
  - у моделей с рассуждением (qwen3, gpt-oss) появляется строка «Рассуждение»: включить,
    выключить или уровень. Если сомневаетесь, оставьте «как в профиле модели».
  - «Показывать запросы к модели во время построения»: лента запросов, пока модель думает
    (раздел 8.4).
  - «Проверять обновления при запуске» (раздел 17).
  - «Проверить обновления»: проверить прямо сейчас.
  - «Скачать модель…»: окно установки Ollama и моделей (раздел 14).

Нажмите «Начать работу» (при повторном открытии кнопка называется «Сохранить»; «Отмена»
закрывает окно без изменений).


5. ИЗ ЧЕГО СОСТОИТ ОКНО

[screens/01-main.png]

Так выглядит вид A после того, как модель qwen2.5:7b построила маршрут вала. Слева направо
четыре колонки.

Верхняя полоса:
  «Чаты»            скрыть или показать левую колонку с историей;
  FORGE             название;
  плашка Ollama     состояние нейросети. Зелёная «Ollama: имя модели» значит, всё готово.
                    Жёлтая: «Ollama не установлена», «Ollama не запущена» или «Нет модели …».
                    По щелчку открывается окно установки (раздел 14);
  «Журнал ошибок»   ошибки модели, которые вы отметили, и уроки из них (раздел 12).
                    Цифра на кнопке показывает, сколько записей ждёт проверки;
  «Обновить до …»   появляется, только когда на GitHub вышла новая версия (раздел 17);
  «Настройки»       тот же экран, что при первом запуске.

Колонка 1, история: «+ Новый чат», поиск и список прошлых расчётов (раздел 13).

Колонка 2, форма детали, сверху вниз:
  «Типовая деталь»      пять готовых примеров, заполняют форму одним щелчком;
  «Деталь»              наименование, обозначение, тип, сталь, программа, шероховатость, нагрев;
  «Геометрия»           из каких простых тел состоит деталь;
  «Кто строит маршрут»  правила или нейросеть, и две главные кнопки:
                        «Построить маршрут» и «Только расчёт».

Колонка 3, результат: шесть плиток с главными числами и вкладки «Маршрут», «Расчёт», «Эскиз»,
«Карты», «Источники», «Печать» (раздел 9). До первого расчёта здесь пусто.

Колонка 4, инженерный чат: вопросы к модели о расчёте и маршруте, правка маршрута словами
(раздел 11). Сюда же программа пишет короткие записи о том, что произошло: «Маршрут:
10 операций, построили правила».


6. ПРИМЕР ЗА ПЯТЬ МИНУТ: СТУПЕНЧАТЫЙ ВАЛ

Этот пример работает и без нейросети. Повторите его один раз, и дальше всё будет понятно.

  1. В блоке «Типовая деталь» нажмите «Вал ступенчатый».
     Форма заполнится: наименование «Вал ступенчатый», обозначение ДП.01.001, тип «Вал, ось,
     цапфа», сталь 45, программа 3000 шт./год, шероховатость 3,2 мкм. В «Геометрии» три
     цилиндра: шейка левая ⌀60×120, средняя ступень ⌀80×200, шейка правая ⌀50×90.
  2. В блоке «Кто строит маршрут» выберите «Правила».
  3. Поставьте галочку «Раскрыть переходы внутри операций».
  4. Нажмите «Построить маршрут». С правилами это занимает меньше секунды.
  5. Сверху появятся плитки. Должно получиться:
       масса детали     11,94 кг
       масса поковки    15,05 кг
       масса заготовки  17,05 кг
       заготовка        ⌀85×383 мм
       КИМ              1,43
       уковка           2,19
  6. На вкладке «Маршрут» будет 10 операций: 005 Заготовительная (резка), 010 Нагревательная,
     015 Штамповка предварительная, 020 Штамповка окончательная, 025 Обрезная, 030 Правка,
     035 Термическая (нормализация), 040 Очистная, 045 Контрольная, 050 Маркирование.
     Под каждой операцией её переходы, например «Установить заготовку ⌀85 мм на пилу, отрезать
     в размер длиной 383 мм».
  7. Откройте вкладку «Расчёт» [screens/02-calc.png]. Техпроцесс: горячая объёмная штамповка
     на молоте, потому что 3000 шт./год попадает в серийное производство. Группа стали М2,
     степень сложности С1, класс точности Т5, исходный индекс 16. Ниже таблица размеров:
     например, диаметр средней ступени 80 мм получает припуск 4 мм, на поковке будет 88 мм.
     Ещё ниже заготовка, нагрев (1200 °C, интервал ковки 1200–800 °C) и оборудование:
     паровоздушный штамповочный молот 2500 кг и обрезной пресс 0,63 МН.
  8. Откройте вкладку «Карты» [screens/04-cards.png]. Это маршрутная карта и карта техпроцесса
     в том виде, в каком они печатаются.
  9. Откройте вкладку «Печать», отметьте нужное и нажмите «Печать / PDF» (раздел 10).
 10. Слева в «Истории» появилась строка «Вал ступенчатый — маршрут, правила». Расчёт сохранён,
     к нему можно вернуться в любой момент.

Попробуйте поменять программу на 10000 и снова нажать «Построить маршрут»: техпроцесс сменится
на штамповку на КГШП. Поставьте 100, и получится свободная ковка.


7. КАК ВВЕСТИ ДЕТАЛЬ

7.1. Типовая деталь

Пять кнопок: «Вал ступенчатый», «Фланец», «Шестерня (диск с отверстием)», «Кольцо», «Рычаг».
Щелчок заменяет всю форму примером. Удобно начинать со своей детали так: выбрать похожий пример
и поправить размеры.

7.2. Блок «Деталь»

Наименование (обязательно). Как деталь называется на чертеже: «Шестерня», «Вал привода».
  Попадает в карты и в название чата. Без него расчёт не запустится.

Обозначение. Номер по чертежу, например ДП.01.001. Можно оставить пустым. Попадает в основную
  надпись карт и в имя файла Excel.

Тип. От типа зависит технология: какие операции нужны и как считаются припуски.
  Вал, ось, цапфа             удлинённая деталь, все ступени на одной оси;
  Рычаг, шатун                удлинённое плоское тело плюс бобышки поперёк;
  Шестерня, диск, ступица     круглая в плане, высота меньше диаметра;
  Кольцо, втулка              круглая с отверстием;
  Фланец, плита               плоская, круглая или прямоугольная;
  Крестовина, вилка           с отростками в разные стороны;
  Комбинированной конфигурации всё, что не подходит под остальные типы.
  FORGE сверяет тип с геометрией и не даст посчитать вал из параллелепипеда (раздел 7.4).

Сталь. Одиннадцать марок: Ст3сп, 20, 35, 45, 40Х, 40ХН, 30ХГСА, 12ХН3А, У8А, ШХ15, 09Г2С.
  От марки зависят плотность, группа стали по ГОСТ 7505, температуры ковки и термообработка.
  Другой марки в списке нет; возьмите ближайшую по химическому составу и учтите это при проверке.

Программа, шт./год. Сколько деталей делают за год. Целое число от 1 до 20 000 000.
  По программе FORGE выбирает вид техпроцесса:
    меньше 200                      свободная ковка: штамп не окупится;
    от 200 до 4999                  штамповка на молоте в многоручьевом штампе;
    5000 и больше                   штамповка на КГШП.
  Если поковка тяжелее 100 кг, при любой программе будет свободная ковка.

Шероховатость Ra, мкм. Самая чистая поверхность детали по чертежу. Допустимо от 0,025
  до 200 мкм, для деталей под механическую обработку обычно 3,2–12,5. Влияет на припуски.

Нагрев. «Пламенная печь» (камерная газовая) или «Индукционный». Влияет на угар металла,
  время выдержки и на то, какой нагреватель попадёт в маршрут.

«Обрабатывается по всем поверхностям». Галочка стоит, если после ковки деталь обтачивают
  со всех сторон. Снимите её, если часть поверхностей остаётся черновой: припуски изменятся.

7.3. Блок «Геометрия»

Деталь описывается набором простых тел. Кнопки внизу блока добавляют тело:
  «+ цилиндр»          поля: диаметр и длина;
  «+ труба»            наружный диаметр D, внутренний d и длина. Внутренний меньше наружного;
  «+ параллелепипед»   A, B, C: длина, ширина, высота.

Все размеры в миллиметрах, по чертежу детали (не поковки: припуски FORGE добавит сам).

У каждого тела:
  поле имени   например «шейка левая». Необязательно, но имена попадают в таблицу размеров
               и в переходы («протянуть шейку левую до ⌀67,4 мм»), так понятнее;
  «Удалить»    убрать тело;
  «вычитается» тело вырезается из детали: отверстие, выточка, паз. Вычитаемый цилиндр
               с длиной, равной высоте детали, даёт сквозное отверстие;
  «вдоль оси»  галочка стоит: тело продолжает деталь по длине, как ступени вала.
               Галочка снята: тело стоит поперёк, как бобышка на рычаге, и длину детали
               не добавляет.

Как разложить деталь на тела. Примеры из типовых деталей:
  ступенчатый вал   три цилиндра подряд, все «вдоль оси»: ⌀60×120, ⌀80×200, ⌀50×90.
                    Общая длина 410 мм получается сама;
  фланец            цилиндр ⌀200×25 (диск) и цилиндр ⌀80×25 с галочкой «вычитается»
                    (центральное отверстие);
  шестерня          цилиндр ⌀180×40 (обод), цилиндр ⌀90×30 (ступица), цилиндр ⌀45×70
                    «вычитается» (отверстие);
  кольцо            одна труба: D 220, d 140, длина 50;
  рычаг             параллелепипед 220×60×30 (тело) и цилиндр ⌀70×40 без галочки
                    «вдоль оси» (бобышка).

Мелочи вроде фасок, галтелей и шпоночных пазов не вводите: в поковке их всё равно нет,
их делают при механической обработке.

7.4. Какие сочетания типа и геометрии FORGE не пропустит

Программа проверяет, похожа ли геометрия на выбранный тип. Если нет, вместо расчёта будет
красное сообщение [screens/14-error.png] с объяснением. Правила такие:

  вал        только цилиндры и трубы, все «вдоль оси», длина больше диаметра;
  шестерня   только тела вращения, все соосны, высота не больше диаметра;
  кольцо     то же, что у шестерни, и обязательно отверстие (труба или вычитаемый цилиндр);
  фланец     все тела соосны, высота не больше диаметра;
  рычаг      нужен параллелепипед, и у него длина больше ширины.

Пример сообщения: «Тип детали «рычаг» не совпадает с геометрией: тело рычага задаётся
параллелепипедом, а здесь только тела вращения — это вал, шестерня или кольцо».
Исправьте тип или тела и нажмите кнопку ещё раз.


8. КТО СТРОИТ МАРШРУТ

8.1. Три режима

  Правила       без нейросети. Маршрут по справочнику FORGE, результат всегда одинаковый,
                строится меньше секунды. Подходит, когда Ollama нет или нужен быстрый ответ.
                Пока выбран этот режим, инженерный чат выключен.
  Один запрос   модель получает всё сразу и одним ответом пишет весь маршрут.
  По частям     на каждое спорное решение модели задаётся отдельный
                вопрос. Запросов больше, но каждый короткий, и ошибок меньше. Режим по умолчанию.
                Спорных решений шесть: осадка, протяжка, предварительная штамповка, прошивка
                отверстия, правка, калибровка.

Что бы ни ответила модель, FORGE проверяет ответ: все ли обязательные операции на месте,
нет ли лишних, правильный ли порядок, не противоречит ли решение геометрии. Если ответ
не прошёл проверку, модель переспрашивают. Если и это не помогло, это место маршрута
строится по правилам, и в результате это видно (метки «модель» и «правила», раздел 9.2).

8.2. «Раскрыть переходы внутри операций»

Без галочки маршрут состоит только из операций. С галочкой под каждой операцией появятся
переходы: «Установить заготовку…», «Нагреть до 1200 °C…». В режиме «Правила» переходы берутся
из справочника, в режимах с моделью их пишет модель, это добавляет запросов и времени.
Для карты техпроцесса по ГОСТ 3.1403 переходы нужны, так что галочку лучше держать включённой.

8.3. «Выбрать модель»

Если поставить галочку, появится список скачанных моделей с размером. Без галочки работает
модель из настроек. Галочка неактивна, пока Ollama не запущена.

8.4. Кнопки и что происходит после нажатия

«Построить маршрут» считает всё и строит маршрут.
«Только расчёт» считает поковку, заготовку, нагрев и оборудование без маршрута. Это быстро
и не трогает нейросеть. Вкладок «Маршрут» и «Карты» после него нет.

Пока модель работает, в колонке результата видно [screens/15-progress.png]:
  - «Запрос 3 из 7 — название этапа» и сколько прошло времени;
  - кнопка «Остановить». Модель прервётся, то, что она успела, останется в маршруте, остальное
    достроят правила;
  - лента запросов (если включена в настройках). Каждая строка это один запрос к модели:
      ✓ принят;
      ↻ брак: ответ не прошёл проверку, модель переспросили;
      ✕ ошибка: модель не ответила;
      ■ остановлен кнопкой;
      … идёт сейчас.
    Полоска показывает время запроса относительно самого долгого.

Сколько ждать. Первый запрос всегда дольше: модель загружается в память. На проверочном
компьютере модель qwen2.5:7b строила маршрут вала по частям 117 секунд, фланца одним запросом
140 секунд. На слабом компьютере без видеокарты может уйти 5–10 минут.


9. КАК ЧИТАТЬ РЕЗУЛЬТАТ

9.1. Плитки

  Масса детали      по геометрии и плотности стали, кг;
  Масса поковки     по номинальным размерам поковки (деталь плюс припуски), кг;
  Масса заготовки   поковка плюс облой, угар и потери на резку, кг;
  Заготовка         диаметр круга по ГОСТ 2590-2006 и длина отрезка, мм;
  КИМ               в FORGE это отношение массы заготовки к массе детали (Мзаг / Мдет).
                    1,43 значит, что на 1 кг детали уходит 1,43 кг металла. Чем ближе к 1,
                    тем меньше отходов;
  Уковка            во сколько раз деформируется металл; для валов обычно не меньше 1,5–2.

9.2. Вкладка «Маршрут»

Сверху метка, кто строил: «правила», «нейросеть» или «нейросеть, по частям». Рядом имя
модели, число запросов и время.

Таблица: номер операции (005, 010, 015…), название и код, оборудование, обоснование. Под
операцией её переходы с меткой «модель» или «правила».

Что ещё может быть на этой вкладке:
  - жёлтое сообщение «Построение остановлено кнопкой…», если вы нажимали «Остановить»;
  - жёлтое сообщение с причиной отката на правила, если модель так и не дала годный ответ;
  - «Модель переспрашивали N раз. Показать ошибки»: что именно было не так в каждом ответе;
  - «Решения модели по операциям»: по каждой спорной операции, нужна она или нет, кто решил
    и почему;
  - синяя плашка «Сравнение с маршрутом по правилам»: процент совпадения, что модель добавила
    и что пропустила;
  - «Модель получила уроков из журнала ошибок: N» (раздел 12);
  - у каждой операции кнопка «Ошибка», если маршрут строила модель.

9.3. Вкладка «Расчёт»

  Поковка: вид техпроцесса и почему выбран; стандарт на припуски; группа стали, степень
  сложности, класс точности и исходный индекс по ГОСТ 7505-89 (для свободной ковки вместо них
  тип поковки по ГОСТ 7829-70); площадь проекции.
  Размеры поковки: для каждого размера детали её значение, припуск, размер поковки, допуск
  и предельные отклонения. Значок «!» у припуска значит, что допуск взят не из ГОСТ.
  Заготовка и нагрев: размер заготовки, облой, выдра (перемычка в отверстии, если есть),
  угар, потери на резку, выдержки, температура нагрева, интервал ковки, нагреватель.
  Справа схема температуры по операциям.
  Оборудование: требуемое усилие или масса падающих частей, выбранная машина и почему
  именно она (например «ближайший больший к расчётному усилию обрезки 0,21 МН»).
  Предупреждения: если что-то в данных выглядит подозрительно.

9.4. Вкладка «Эскиз»

[screens/03-sketch.png]
Контур детали и поверх него контур поковки с размерами. Это схема для проверки на глаз,
чертёж поковки FORGE не делает.

9.5. Вкладка «Карты»

[screens/04-cards.png]
Маршрутная карта (МК) по ГОСТ 3.1118-82 и карта технологического процесса ковки и штамповки
(КТП) по ГОСТ 3.1403-85, с основной надписью по ГОСТ 3.1103-82. Строки А, Б, О, М заполнены
из маршрута и расчёта. Графы «Разраб.», «Пров.», «Н. контр.», «Утв.» остаются пустыми
для подписей.

9.6. Вкладка «Источники»

[screens/05-sources.png]
Откуда взято каждое число. Две части:
  «Из стандартов»: какие ГОСТ использованы и что именно из каждого взято;
  «Не из ГОСТ — сверить перед подписью»: числа, которых в стандартах нет (потери металла,
  температуры, выдержки, усилия). У каждого метка:
    сверить               приближённая формула, значение оценочное. Проверять в первую очередь;
    указание технолога    норма со слов практикующего технолога;
    заводская норма       так считают на заводе, стандарт величину не задаёт;
    справочник            из справочной литературы, номер в квадратных скобках ведёт
                          к списку «Литература» под таблицей;
    расчёт                посчитано программой из величин выше.


10. ПЕЧАТЬ, PDF И EXCEL

[screens/06-print.png]

Вкладка «Печать». Галочками выберите, что попадёт на бумагу:
  расчёт, эскиз, маршрут, переходы, источники   рабочий лист на А4;
  карта ГОСТ 3.1118                             маршрутная карта, А4 альбомная;
  карта ГОСТ 3.1403                             карта техпроцесса, А4 альбомная.
Карты по умолчанию выключены: включите их, если нужны. Серые пункты недоступны, например
маршрута нет после «Только расчёт».

PDF. Нажмите «Печать / PDF». Откроется окно печати браузера. В поле «Принтер» выберите
«Сохранить как PDF», нажмите «Сохранить» и выберите папку. Имя файла FORGE подставит сам:
«FORGE — Вал ступенчатый — 2026-11-13 14-05». Поля и ориентацию менять не нужно, карты сами
встают на альбомный лист.

Бумага. То же самое, но в поле «Принтер» выберите свой принтер.

Excel. Кнопка «Карты в Excel» сохраняет обе карты в файл .xlsx, по листу на карту. Файл
ложится в папку exports рядом с программой, имя вида «ДП.01.001_карты_2026-11-13_14-05-30.xlsx».
Путь к файлу появится в чате. Браузер может дополнительно скачать копию в «Загрузки».
Кнопка есть, только когда построен маршрут.

Рабочий лист (расчёт, маршрут) оформлен не по ЕСТД, это написано на нём самом. По ЕСТД
оформлены карты.


11. ИНЖЕНЕРНЫЙ ЧАТ

Правая колонка. Вопросы задаёт человек, отвечает модель, но числа в ответе FORGE сверяет
с расчётом. Чату нужна нейросеть: если в настройках выбрано «Без нейросети» или в форме
выбраны «Правила», поле ввода серое и под ним написано почему.

Отправить: Enter. Новая строка: Shift+Enter. Пока модель думает, есть кнопка «Остановить».
Модель помнит последние шесть сообщений чата.

11.1. Четыре режима (кнопки над перепиской)

Объяснить [screens/16-chat.png]. Вопросы про текущий расчёт и маршрут: «почему припуск на диаметр 4 мм?»,
  «зачем операция 030 Правка?». Нужен готовый расчёт.

Правка маршрута. Попросите словами: «убери правку», «добавь контрольную после термообработки».
  Модель предложит изменение, FORGE применит его к копии маршрута и проверит. В чате появится
  блок «Предлагаемая правка маршрута» со строками «+» (добавить) и «−» (убрать) и кнопками
  «Принять» и «Отклонить». После «Принять» маршрут и карты обновятся, а на вкладке «Маршрут»
  останется пометка, что он изменён вручную. Если правка ломает технологию (например, убрать
  окончательную штамповку), FORGE её не предложит и напишет почему. Нужен построенный маршрут.

Что если [screens/17-whatif.png]. «А если сталь 40Х?», «а если 10000 штук в год?»,
  «а если средняя ступень ⌀90?».
  Менять можно: марку стали, программу, нагрев, шероховатость, галочку обработки по всем
  поверхностям и размеры тел. FORGE пересчитает всё сам и покажет таблицу «Было / Вариант»,
  изменившиеся строки выделены. «Открыть вариант» заменит форму и расчёт вариантом (маршрут
  у варианта по правилам; чтобы его построила модель, нажмите «Построить маршрут»).
  «Оставить как было» ничего не меняет.
  Над таблицей строка «Вариант:», в ней всё, что поменялось. FORGE сверяет её с вопросом:
  если модель поменяла то, о чём не спрашивали (спросили про программу, а она меняет диаметр),
  вариант не принимается и модель переспрашивают. Если и со второго раза не вышло, в чате
  будет «Вариант не прошёл проверку и не пересчитан» с причиной. Переформулируйте вопрос,
  назвав поле прямо: «а если программа 10000 шт. в год?», «а если сталь 40Х?».
  Предыдущие сообщения чата в этом режиме модели не передаются, каждый вопрос отдельный.

Консультация. Общие вопросы о ковке и штамповке, не про конкретную деталь: «чем КГШП лучше
  молота?». Расчёт не нужен. Ответ из общих знаний модели, поэтому помечен «не из расчёта,
  проверить по справочнику».

11.2. Пометки под ответом

  «числа сверены с расчётом»   все числа из ответа есть в расчёте;
  «не из расчёта: 4,5; 12»     модель назвала числа, которых в расчёте нет. Им не верьте
                               без проверки;
  серые плашки                 источники, на которые ссылается ответ;
  «уроков: N»                  сколько уроков из журнала ошибок получила модель (наведите
                               мышь, чтобы прочитать);
  «Ошибка»                     отметить, что модель ошиблась в этом ответе (раздел 12).

В виде B можно щёлкнуть любую строку таблицы на листе, и в чате появится готовый вопрос
«Объясни строку листа: …». В виде C у выбранной операции есть кнопка «Спросить об операции».


12. ЖУРНАЛ ОШИБОК МОДЕЛИ

Если модель ошиблась, это можно записать, и в следующий раз FORGE подскажет ей правильный
ответ. Так модель учится на ваших поправках без переобучения.

12.1. Как отметить ошибку

[screens/09-mistake.png]
Кнопка «Ошибка» есть в трёх местах: у операции в маршруте (если его строила модель), под
ответом в чате и в шапке чата. Откроется окно «Ошибка модели»:
  Операция                   к какой операции относится ошибка или «весь маршрут / ответ
                             в целом»;
  Что сделала модель         заполнено само, можно поправить;
  Как правильно              главное поле. Пишите так, как объяснили бы студенту:
                             «обрезку облоя ставят сразу после окончательной штамповки,
                             до термообработки». Этот текст станет уроком;
  только для деталей типа …  галочка: урок касается только этого типа детали. Снимите,
                             если правило общее.
Нажмите «В журнал». Если на эту операцию урок уже есть, окно предложит «Это та же ошибка,
отметить повтор»: так видно, какие модели не слушаются уроков.

12.2. Журнал

[screens/10-lessons.png]
Кнопка «Журнал ошибок» в шапке. Вкладки:
  На проверке   новые записи. Модель их пока не видит. Прочитайте, поправьте текст урока
                в поле «урок, как его прочитает модель» и нажмите «Принять» или «Отклонить»;
  Уроки         принятые. Они уходят модели в каждый подходящий запрос. Видно, сколько раз
                урок использован и повторялась ли ошибка после него. «Отключить» убирает
                урок из запросов, не удаляя;
  Отклонённые   «Вернуть на проверку» или удалить;
  По моделям    таблица: сколько ошибок отмечено у каждой модели, сколько из них стали
                уроками и сколько раз модель повторила ошибку после урока.
«Удалить» спрашивает подтверждение вторым нажатием.

Часть уроков приходит вместе с программой, это замечания технолога, у них метка
«замечание технолога».


13. ИСТОРИЯ ЧАТОВ

Каждый расчёт и каждый маршрут автоматически сохраняется как чат: деталь, результат и вся
переписка. Список в левой колонке, сгруппирован по дням: «Сегодня», «Вчера», «На этой неделе»,
«Ранее». Под названием обозначение детали, модель (или «правила») и время.

  Открыть        щелчок по чату. Форма, результат и переписка вернутся как были;
  Новый чат      «+ Новый чат», чистый экран. Старый чат никуда не денется;
  Поиск          поле «Поиск по чатам…» ищет по названию, обозначению, наименованию детали
                 и модели;
  Переименовать  кнопка «Имя» при наведении на чат;
  Удалить        кнопка «×». Удаляется насовсем, программа переспросит.

Название чата FORGE придумывает сам: «Вал ступенчатый — маршрут, правила» или первые слова
первого вопроса.


14. НЕЙРОСЕТЬ: УСТАНОВКА OLLAMA И МОДЕЛИ

Без нейросети FORGE работает полностью, кроме инженерного чата. Если нейросеть нужна,
всё ставится из самой программы.

[screens/08-model-setup.png]
Откройте окно «Скачать модель»: щелчок по жёлтой плашке Ollama в шапке или «Настройки» →
«Скачать модель…». В окне три шага.

  Шаг 1. Ollama. Кнопка «Установить Ollama». Windows спросит права администратора, ответьте
         «Да». Установка идёт через winget, лог виден внизу окна. Если winget нет, скачайте
         установщик вручную с https://ollama.com/download и запустите его.
  Шаг 2. Сервис Ollama. Кнопка «Запустить Ollama». После этого справа внизу Windows появится
         значок ламы. При следующих включениях компьютера Ollama обычно стартует сама.
  Шаг 3. Модель. Модели разбиты на три группы по мощности компьютера:
           Слабый компьютер    8 ГБ памяти, без видеокарты:
                               qwen3:4b (2,5 ГБ), gemma3:4b (3,4 ГБ);
           Обычный компьютер   16 ГБ памяти или видеокарта от 6 ГБ:
                               qwen2.5:7b (4,7 ГБ, основная), YandexGPT-5-Lite-8B (4,9 ГБ,
                               лучше пишет по-русски);
           Мощный компьютер    видеокарта от 12 ГБ или 32 ГБ памяти:
                               gemma3:12b, qwen2.5:14b, qwen3:30b, gemma3:27b (8–19 ГБ).
         Метка «испытана» значит, что под модель настроены запросы и её прогоняли на типовых
         деталях. Если не знаете, что брать, берите qwen2.5:7b. Нажмите «Скачать» и ждите:
         4,7 ГБ на обычном интернете это 5–15 минут. В нижнем поле можно вписать любую
         другую модель с ollama.com/library.

Окно само замечает, что шаг выполнен (раз в 15 секунд или по кнопке «проверить снова»).
Когда плашка в шапке станет зелёной «Ollama: qwen2.5:7b…», откройте «Настройки», выберите
модель в правой половине и нажмите «Сохранить».

Видеокарта. Модель работает намного быстрее на видеокарте NVIDIA. На ноутбуке с двумя
видеокартами Ollama должна видеть дискретную; проверить можно командой nvidia-smi в консоли,
пока модель отвечает. При долгой работе видеокарта сильно греется, это нормально, но
ноутбуку лучше стоять на твёрдой поверхности.

Рассуждающие модели (qwen3, gpt-oss) сначала «думают», потом отвечают. Это дольше, а длинное
рассуждение может не уместиться в окно модели, и ответ оборвётся. Если так происходит,
в «Настройках» у модели поставьте «Рассуждение: выключено».


15. ТРИ ВИДА ЭКРАНА: A, B, C

Переключается в «Настройках». Расчёт и данные во всех трёх видах одни и те же.

A. Рабочее место [screens/01-main.png]
   Четыре колонки: история, форма, результат с вкладками, чат. Всё видно сразу. Удобно на
   широком мониторе и для первого знакомства.

B. Лист + ассистент [screens/11-layout-b.png], [screens/12-layout-b-card.png]
   В центре результат в виде бумажного листа, как он будет напечатан. Вкладки «Лист»,
   «МК ГОСТ 3.1118», «КТП ГОСТ 3.1403», «Печать». Форма спрятана, её открывает кнопка
   «Деталь» в шапке. Щелчок по строке листа задаёт вопрос о ней в чате.

C. Пульт технолога [screens/13-layout-c.png]
   Тёмный экран (если тема «Как в системе»). Сверху маршрут в виде цепочки карточек
   операций и график температуры по операциям. Горячие операции подчёркнуты. Щёлкните
   операцию, справа будут её оборудование, кто решил, обоснование, переходы и кнопки
   «Спросить об операции» и «Ошибка в операции». Ниже вкладки результата, внизу чат
   и история. Форма открывается кнопкой «Деталь».

Если окно узкое (меньше 1400 точек), история прячется сама, кнопка «Чаты» показывает её
поверх остального.


16. ВСЕ НАСТРОЙКИ

Кнопка «Настройки» в шапке. Изменения применяются после «Сохранить», «Отмена» всё
возвращает.

  Вид экрана               A, B или C (раздел 15);
  Тема                     как в системе, светлая, тёмная;
  Цвет                     любой цвет кнопок и выделения. Яркость FORGE подправит сам, чтобы
                           текст на кнопках читался и в светлой, и в тёмной теме.
                           «Как в пульте» возвращает исходный цвет;
  Модель                   какой моделью строить маршрут и отвечать в чате, или «Без нейросети».
                           Метки «испытана» / «не испытана» (раздел 14);
  Рассуждение              только у рассуждающих моделей: как в профиле, включено, выключено
                           (у gpt-oss: низкий, средний, высокий уровень);
  Показывать запросы       лента запросов во время построения (раздел 8.4);
  Проверять обновления     смотреть при запуске, нет ли новой версии на GitHub;
  Проверить обновления     проверить сейчас, ответ появится рядом с кнопкой;
  Скачать модель…          окно установки Ollama и моделей (раздел 14).

Без кнопки «Сохранить» FORGE запоминает: выбранный режим («Правила»,
«Один запрос», «По частям»), галочку «Раскрыть переходы» и модель из «Выбрать модель».


17. ОБНОВЛЕНИЯ

FORGE.exe при каждом запуске смотрит, нет ли на GitHub версии новее.
Если есть, в шапке появляется кнопка «Обновить до 1.0.1» (номер будет свой).

  1. Нажмите её. Откроется окно с номером версии и списком изменений.
  2. Нажмите «Обновить сейчас».
  3. FORGE скачает новый FORGE.exe, закроется, заменит файл и откроется снова уже новой
     версией. Обычно это меньше минуты. Настройки, история и журнал ошибок сохраняются.

FORGE скачивает обновление только с github.com и только если это программа Windows.
Если интернета нет, проверка молча не сработает, работать это не мешает.

Если обновление не встало (например, файл заблокирован антивирусом), появится чёрное окно
с текстом «Не удалось заменить FORGE.exe». Закройте FORGE и запустите файл forge-update.bat
из папки с программой ещё раз. Или просто скачайте новый FORGE.exe из релиза вручную
и замените старый.

Если FORGE запущен из исходников, вместо установки будет ссылка на страницу релиза:
код обновляется вручную (скачать заново или git pull).

Проверку при запуске можно выключить в «Настройках».


18. ГДЕ ПРОГРАММА ХРАНИТ ФАЙЛЫ

Всё лежит рядом с FORGE.exe (или в папке с кодом, если запуск из исходников):

  settings.json     настройки;
  history\          история чатов, по файлу на чат;
  lessons.json      журнал ошибок и уроки;
  exports\          карты в Excel;
  forge.log         журнал запуска: адрес, ошибки окна. Пригодится, если что-то не открылось;
  models\           (необязательно) свои профили моделей.

Чтобы перенести FORGE на другой компьютер со всей историей, скопируйте папку целиком.
Чтобы начать с чистого листа, удалите settings.json (снова появится экран первого запуска),
history и lessons.json.

Во время обновления на несколько секунд появляются FORGE.new.exe и forge-update.bat,
потом они исчезают сами.


19. ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

Сообщения при расчёте (красная плашка в колонке результата):

  «Не заполнено наименование детали»
      Впишите наименование в блоке «Деталь».

  «Нужен хотя бы один элемент геометрии»
      Добавьте тело кнопкой «+ цилиндр», «+ труба» или «+ параллелепипед».

  «Элемент 2 (цилиндр): нужны диаметр и длина»
      У второго тела сверху пустое поле. Номер считается сверху вниз.

  «Элемент 1 (труба): внутренний диаметр не меньше наружного»
      Перепутаны D и d.

  «Элемент 1: размер 'l' равен 41000 мм — это 41 м…»
      Лишний ноль. Размеры в миллиметрах, предел 20 м.

  «Тип детали «…» не совпадает с геометрией: …»
      См. раздел 7.4. В сообщении написано, что именно не так.

  «Программа выпуска … слишком велика» / «должна быть больше нуля»
      Программа от 1 до 20 000 000 шт./год.

  «Шероховатость Ra = … мкм вне разумных пределов»
      Допустимо от 0,025 до 200 мкм.

  «Движок не отвечает»
      Программа закрылась, а окно осталось. Закройте окно и запустите FORGE снова.

Нейросеть:

  Плашка «Ollama не установлена» или «Ollama не запущена»
      Щёлкните по плашке и пройдите шаги 1–2 (раздел 14).

  Плашка «Нет модели …»
      Ollama работает, но выбранная модель не скачана. Шаг 3, или выберите в «Настройках»
      другую скачанную модель.

  Маршрут строится очень долго
      Посмотрите ленту запросов. Если запросы идут, а каждый по минуте и больше, компьютеру
      тяжело: возьмите модель полегче, режим «Один запрос» или «Правила». Можно нажать
      «Остановить»: готовое останется, остальное достроят правила.

  «Откат на правила: …»
      Модель несколько раз ответила не по формату или с ошибкой. Маршрут всё равно есть,
      он по правилам. Причина написана в сообщении. Часто помогает другая модель.

  «кончилось окно в N токенов» / «модель не остановилась сама»
      Ответ модели оборвался. У рассуждающих моделей выключите рассуждение (раздел 14).

  Чат серый, «Чат недоступен: в настройках выбрано «Без нейросети»»
      Выберите модель в «Настройках» и режим «Один запрос» или «По частям» в форме.

  «Сначала посчитайте деталь или постройте маршрут» / «Править нечего: сначала постройте маршрут»
      Режимам «Объяснить», «Что если» и «Правка маршрута» нужен результат.

Окно и запуск:

  Синее окно «Windows защитила ваш компьютер»
      «Подробнее» → «Выполнить в любом случае» (раздел 3.1).

  Окно не открылось
      См. раздел 3.3 и файл forge.log.

  Окно закрыл, а программа ещё висит в диспетчере задач
      Если браузер передал окно своему другому процессу, FORGE выключится сам примерно через
      три минуты после закрытия окна.

  Печать режет карту
      В окне печати проверьте, что масштаб «По умолчанию» и не выбран «Подогнать по ширине».
      Карты рассчитаны на А4 альбомный без полей принтера.


20. ОГРАНИЧЕНИЯ ВЕРСИИ 1.0

  - При свободной ковке оборудованием выбирается гидравлический пресс, хотя припуски идут
    по ГОСТ 7829-70, который написан для молотов. Подбор ковочного молота по массе поковки
    ждёт источника.
  - Рассуждающие модели с длинным рассуждением (например qwen3.5:4b) не помещаются в окно
    8192 токена, для них рассуждение лучше выключить.
  - Режимы термообработки легированных сталей, которых нет в ГОСТ, помечены «не ГОСТ».
  - Деталь описывается только цилиндрами, трубами и параллелепипедами. Конусы, сферы
    и сложные поверхности нужно приближать ими.
  - В списке одиннадцать марок стали.
