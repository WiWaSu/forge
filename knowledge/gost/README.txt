Как устроены таблицы 3 и 8

Главное, без чего расчёт не сходится: «толщина детали» и «длина, ширина, диаметр,
глубина и высота» ведут в один и тот же столбец таблицы разными путями.
Для толщинного размера столбец берётся по интервалу толщины, для остальных — по интервалу
самого размера. Внутри столбца припуск выбирается по требуемой шероховатости
(Rz 100…12,5 / Ra 10…1,6 / Ra 1,25 и точнее).

Значение определяется положением в числовом ряду:

    позиция = (исходный индекс - 1) + номер столбца

Поэтому вместо 23 × 27 чисел хранятся три ряда припусков и один ряд допусков
по 31 значению плюс таблица интервалов.

Правило исходного индекса (таблица 2)

    индекс = база(масса) + сдвиг(M) + сдвиг(C) + сдвиг(T)

Класс точности сдвигает индекс на 2 за ступень, группа стали и степень сложности —
на 1. Максимум правила 10 + 2 + 3 + 8 = 23 совпадает с верхней границей индекса.

Чем проверено

Приложение 5 стандарта содержит полностью разобранный пример: шестерня привода,
сталь 30ХМА, масса детали 0,390 кг. Движок воспроизводит его целиком:

| Что | В стандарте | Движок |
|---|---|---|
| расчётная масса поковки | 0,620 кг | 0,620 кг |
| степень сложности | С1 (Gп/Gф = 0,79) | С1 |
| исходный индекс | 6 | 6 |
| припуск на диаметр 60 при Ra 6,3 | 1,0 мм | 1,0 мм |
| припуск на диаметр 34 при Ra 0,8 | 1,0 мм | 1,0 мм |
| припуск на толщину 31 при Ra 6,3 | 1,0 мм | 1,0 мм |
| припуск на толщину 31 при Ra 0,8 | 1,1 мм | 1,1 мм |
| припуск на толщину 21 при Ra 6,3 | 0,9 мм | 0,9 мм |
| допуск диаметра 62 | 0,9 (+0,6/−0,3) | то же |
| допуск диаметра 36 | 0,8 (+0,5/−0,3) | то же |

Проверяется тестами test_gost_example_* при каждом запуске.
